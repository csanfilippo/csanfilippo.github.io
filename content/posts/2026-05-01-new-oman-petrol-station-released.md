[oman-petrol-stations](https://github.com/csanfilippo/oman-petrol-stations) v1.2.0 is out.

The code had been sitting untouched for a while — I finally found the time to go through it and clean things up. A few silent bugs got fixed along the way (KML files had coordinates in the wrong order, Al Maha would return an empty list instead of an error when parsing failed), plus some structural improvements.

Full details in the [release notes](https://github.com/csanfilippo/oman-petrol-stations/releases/tag/1.2.0).
