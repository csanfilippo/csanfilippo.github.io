Indicates that an element has ended.

Parameters

The qualified name of the element (e.g. dc:title). Equal to localName when there is no prefix.

namespaceURI

The namespace URI, or null if the element has no namespace.

localName

The local name of the element without any namespace prefix (e.g. title).
